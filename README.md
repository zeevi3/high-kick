# היי קיק: אפליקציית אימון לבעיטה גבוהה

## הרצה במחשב (Mac)

1. פותחים את Terminal.
2. מקלידים `cd ` (עם רווח בסוף), גוררים את התיקייה `high-kick` לתוך החלון ולוחצים Enter.
3. מריצים:
   ```
   python3 -m http.server 8000
   ```
4. פותחים בדפדפן: http://localhost:8000
5. כדי לעצור: Ctrl+C בחלון ה־Terminal.

אי אפשר לפתוח את `index.html` בלחיצה כפולה: בצורה הזו העבודה בלי אינטרנט לא פועלת.

## העלאה לאינטרנט בחינם, והתקנה בטלפון

### אפשרות 1: GitHub Pages (כתובת קבועה)
1. נכנסים ל־github.com, ולוחצים New repository. שם: `high-kick`. מסמנים Public ולוחצים Create.
2. בעמוד המאגר לוחצים uploading an existing file, גוררים את **כל מה שבתוך** התיקייה `high-kick` (הקבצים והתיקיות `js` ו־`icons`), ולוחצים Commit changes.
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: `main`, תיקייה `/ (root)` ← Save.
4. אחרי דקה־שתיים האפליקציה זמינה בכתובת `https://<שם-המשתמש>.github.io/high-kick/`.

### אפשרות 2: Netlify Drop (הכי מהיר)
1. נכנסים ל־app.netlify.com/drop.
2. גוררים את התיקייה `high-kick` לעמוד.
3. כדי שהאתר יישאר, צריך להירשם (חינם) וללחוץ Claim.

### התקנה בטלפון
- **אייפון:** פותחים את הכתובת ב־Safari ← כפתור השיתוף ← "הוסף למסך הבית".
- **אנדרואיד:** פותחים ב־Chrome ← תפריט ⋮ ← "התקן אפליקציה" או "הוסף למסך הבית".

אחרי הפתיחה הראשונה האפליקציה עובדת גם בלי אינטרנט. הסרטונים עדיין צריכים אינטרנט.

## עדכון האפליקציה
מעלים מחדש את הקבצים ששונו. הטלפון מוריד את הגרסה החדשה ברקע, והיא מופיעה בפתיחה הבאה.

## גיבוי
כל הנתונים נשמרים רק בטלפון. כדאי לפעמים להיכנס להגדרות ← "ייצוא כל הנתונים" ולשמור את הקובץ.
מחיקת נתוני האתר בדפדפן או הסרת האפליקציה מוחקות את הנתונים.
